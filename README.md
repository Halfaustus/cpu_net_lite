# CPU_NET_Lite V1.1

面向 Windows 的校园网连接工具，维护者 Halfaustus。保留校园网/宿舍网登录、自动重连、TUN 共存、托盘、电源选项和日志。当前源码版本为 **1.1.0**，需要 **.NET 10 Windows Desktop Runtime**。

## 构建与启动

在项目根目录执行：

```powershell
dotnet build .\cpu_net.sln -c Release
dotnet publish .\cpu_net.csproj -c Release --self-contained false -o .\artifacts\V1.1
.\artifacts\V1.1\cpu_net.exe
```

`artifacts/V1.1` 为本次1.1.0独立编译目录，属于依赖框架的文件夹版本；已有V1.0及其他运行目录未替换。V1.1仅在本地Git归档，未推送或发布，新增行为仍待人工验收。`--preview` 可预览界面，不认证、不保存设置、不执行自动任务。当前不提供 CLI、一键安装器、自动更新或新的 GitHub 安装包 Release。

## 配置与连接

- 账号、密码、运营商通过“保存网络配置”一起保存；下方其他设置修改后立即保存，不带入未保存的账号草稿。
- 配置位于程序旁的 `config.yaml`，当前兼容格式包含明文凭据，不随源码或分发包提交。旧模块字段仅被动保留。新目录运行时需要自行配置；升级时可保留自己原目录的配置。
- 可选择校园网优先或宿舍网优先，逐个确认认证 IP 并登录，成功或已在线即停止；宿舍网需要有效运营商。
- 默认检测间隔为10秒，范围1～86400秒；每轮结束后再等待间隔。已有配置不自动覆盖。关闭定时检测/网络登录或缺少有效凭据时不调度。
- 任一登录轮次开始后30秒内不再自动登录；手动登录不受冷却限制，但需等待正在执行的登录流程结束。每次实际开始的手动登录都会刷新自动登录的冷却时间。冷却期间自动跳过，外网检测仍继续。
- “增强模式”默认关闭，单独即时保存。开启后，外网状态不明时不限次数重连，仍须开启网络登录、定时检测并保存有效凭据；每轮先确认认证IP。成功或已在线只结束当前轮，若外网仍状态不明，冷却结束后继续尝试。关闭增强模式后未知状态仅探测；外网正常时不触发重连。旧UnknownReconnectAttempts字段仅兼容保留，不决定新开关值。已知门户、手动和启动登录沿用原规则。
- 请求绕过应用层HTTP代理，仍可能经过系统TUN。认证地址为宿舍网 `172.17.253.3`、校园网 `192.168.199.21`，按所用代理软件配置直连/路由排除。本程序不修改代理、路由或网卡。

## 窗口、启动与电源

窗口可调整大小；启用“启动时收起”后，从系统托盘打开窗口。关闭窗口或使用托盘退出会询问是否退出，确认后结束程序。

“开机启动”仅在用户切换时更新当前用户的CPU_NET_Lite启动项，取消勾选即可关闭。移动程序目录后，需要用户重新设置启动项。不会清理其他版本的启动项。

“阻止系统休眠”默认开启，“阻止屏幕关闭”默认关闭，二者独立即时保存和应用；退出时释放本程序的电源请求。

## 日志

设置侧栏提供“日志配置”快速跳转。新版运行日志为程序目录下 `Log/runtime.log` 及 `runtime.1.log`～`runtime.4.log`，最多保留5个文件，默认单文件10MB，可设1～100MB。超限覆盖最旧滚动文件。旧月度日志、异常日志及备用日志保留，不属于该总量限制。

相同外网探测异常每5分钟汇总；状态变化和认证明细保留。主页最多显示500行，支持选择、Ctrl+C、右键复制；“清空日志”仅清空显示，不删除磁盘日志。窗口隐藏时暂停日志界面刷新。

外网探测异常时，界面及运行日志只显示简短原因和诊断文件的绝对路径。完整信息保存在程序旁 `Diagnostics/probe-时间-GUID.txt`：检测时间、检测地址、HTTP状态、完整Content-Type、Location、耗时、正文字符数、完整响应正文，或异常类型和原因。响应正文及Location不脱敏、不截断；检测地址仍去除查询、用户信息及动态路径。不读取或附带认证请求凭据、Cookie、其他请求头或本地配置，不自动上传。

诊断只保留最近20份本程序命名格式的文件，写入新文件前删除最旧文件；采用数量上限，单份正文没有长度/容量上限。相同异常（比较完整正文、Location、状态、类型和原因，排除时间/耗时）只生成一份，持续时按5分钟汇总并引用原文件；内容变化或恢复后再次异常生成新文件。写入或保留清理失败只在运行日志显示错误原因，不显示未成功写入的路径，不中断探测或重连。恢复正常记录恢复时间，联网判定及增强模式规则不变。
HTTP 200 返回HTML时，也可识别已确认的宿舍网认证模板：静态跳转或认证链接指向已知宿舍主机的 `/a79.htm` 并具有相应门户参数。命中提示“检测到已知宿舍网认证页面（HTTP 200 正文跳转）”，不需要开启增强模式；仍需启用网络登录和定时检测并保存有效凭据。不会执行页面脚本或访问跳转地址，不把 `wlanacip` 作为设备IP，认证顺序仍由用户设置决定，设备IP仍从状态接口确认。自动冷却与正常外网判定不变，未明确识别的页面仍按状态不明处理。
