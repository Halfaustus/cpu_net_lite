# CPU_NET_Lite V1.0

面向 Windows 的校园网连接工具，维护者 Halfaustus。保留校园网/宿舍网登录、自动重连、TUN 共存、托盘、电源选项和日志。当前版本为 **1.0.0**，需要 **.NET 10 Windows Desktop Runtime**。

## 构建与启动

在项目根目录执行：

```powershell
dotnet build .\cpu_net.sln -c Release
dotnet publish .\cpu_net.csproj -c Release --self-contained false -o .\artifacts\V1.0
.\artifacts\V1.0\cpu_net.exe
```

`artifacts/V1.0` 为唯一正式分发目录，属于依赖框架的文件夹版本。`--preview` 可预览界面，不认证、不保存设置、不执行自动任务。当前不提供 CLI、一键安装器、自动更新或新的 GitHub 安装包 Release。

## 配置与连接

- 账号、密码、运营商通过“保存网络配置”一起保存；下方其他设置修改后立即保存，不带入未保存的账号草稿。
- 配置位于程序旁的 `config.yaml`，当前兼容格式包含明文凭据，不随源码或分发包提交。旧模块字段仅被动保留。新目录运行时需要自行配置；升级时可保留自己原目录的配置。
- 可选择校园网优先或宿舍网优先，逐个确认认证 IP 并登录，成功或已在线即停止；宿舍网需要有效运营商。
- 默认检测间隔为10秒，范围1～86400秒；每轮结束后再等待间隔。已有配置不自动覆盖。关闭定时检测/网络登录或缺少有效凭据时不调度。
- 启动、手动及自动登录各轮开始共用30秒间隔；冷却期间自动跳过且不扣次数，手动登录提示剩余时间。外网检测仍继续。
- 外网状态不明时有限重连默认3轮，可设0～100，0关闭。一轮没有取得认证IP也计数。成功或已在线停止本次状态不明期间的尝试；达到上限后继续探测。外网恢复正常或重启进程后重新计数，修改设置不清零。已知门户、手动和启动登录不受这个次数上限限制，但仍遵守30秒间隔。
- 请求绕过应用层HTTP代理，仍可能经过系统TUN。认证地址为宿舍网 `172.17.253.3`、校园网 `192.168.199.21`，按所用代理软件配置直连/路由排除。本程序不修改代理、路由或网卡。

## 窗口、启动与电源

窗口可调整大小；启用“启动时收起”后，从系统托盘打开窗口。关闭窗口或使用托盘退出会询问是否退出，确认后结束程序。

“开机启动”仅在用户切换时更新当前用户的CPU_NET_Lite启动项，取消勾选即可关闭。移动程序目录后，需要用户重新设置启动项。不会清理其他版本的启动项。

“阻止系统休眠”默认开启，“阻止屏幕关闭”默认关闭，二者独立即时保存和应用；退出时释放本程序的电源请求。

## 日志

设置侧栏提供“日志配置”快速跳转。新版运行日志为程序目录下 `Log/runtime.log` 及 `runtime.1.log`～`runtime.4.log`，最多保留5个文件，默认单文件10MB，可设1～100MB。超限覆盖最旧滚动文件。旧月度日志、异常日志及备用日志保留，不属于该总量限制。

相同外网探测异常每5分钟汇总；状态变化和认证明细保留。主页最多显示500行，支持选择、Ctrl+C、右键复制；“清空日志”仅清空显示，不删除磁盘日志。窗口隐藏时暂停日志界面刷新。
